Tujuan file ini: membantu AI coding agent memahami konteks minimum project di awal sesi sebelum menerima task utama.

Fase ini hanya BOOTSTRAP.

Ini BUKAN template untuk mengerjakan bug fix, feature, refactor, atau implementation task. Aturan implementasi dan skill kerja ada di template/instruction lain yang berlaku saat task utama diberikan.

PRINSIP UTAMA

Pahami repo dengan biaya konteks minimum yang masih cukup untuk mengetahui:

* stack utama,
* struktur folder inti,
* cara menjalankan project,
* aturan coding penting,
* dan sumber konteks yang tersedia.

Jangan audit seluruh repository.

Jangan mengubah file.

Jangan mulai implementasi.

INSTRUCTION CONTEXT DULU

Hormati instruction yang sudah otomatis dimuat oleh coding agent saat ini.

Project dapat memiliki instruction seperti:

* AGENTS.md
* AGENTS.override.md
* CLAUDE.md
* GEMINI.md
* .cursor/rules/
* .github/copilot-instructions.md
* .github/instructions/
* opencode config/instructions
* atau mekanisme agent lain.

Jangan menganggap semua agent memakai file atau hierarchy yang sama.

Jangan membaca ulang instruction panjang hanya untuk menduplikasi context jika current agent sudah memuatnya.

Jika perlu mengetahui instruction yang berlaku tetapi belum tersedia di context, lakukan discovery minimum sesuai mekanisme agent saat ini.

Jangan mencampur file template `Agents.md` dengan native `AGENTS.md` kecuali wiring project memang menjadikannya satu sumber yang sama.

FAST CONTEXT LAYER

Jika tersedia dan sudah dikonfigurasi untuk repository ini, prioritaskan context accelerator yang sudah ada sebelum melakukan eksplorasi source yang luas.

Contoh:

CLAUDE-MEM / PROJECT MEMORY

Gunakan search, observation, timeline, atau mekanisme retrieval yang tersedia untuk mengambil konteks relevan dari sesi sebelumnya.

GRAPHIFY

Jika tersedia:

`graphify-out/graph.json`

gunakan query yang sudah ada seperti:

* graphify query
* graphify path
* graphify explain

untuk memahami dependency, flow, symbol, atau struktur project.

JANGAN menjalankan rebuild/full Graphify pada fase bootstrap.

JANGAN membuat graph baru hanya karena graph lama tidak tersedia.

Context accelerator adalah jalur cepat, bukan source of truth absolut.

Jika memory atau graph:

* tidak tersedia,
* kosong,
* tidak relevan,
* stale,
* bertentangan dengan repository,
* atau tidak cukup menjawab kebutuhan bootstrap,

lanjutkan dengan targeted repository inspection.

Untuk fakta kondisi project saat ini, repository dan konfigurasi aktual lebih dipercaya daripada memory/index lama.

JIKA TOOL TIDAK TERSEDIA

Jangan gagal bootstrap hanya karena:

* claude-mem tidak tersedia,
* graphify tidak tersedia,
* MCP tertentu tidak tersedia,
* atau agent saat ini tidak mendukung tool tersebut.

Lewati tool tersebut dan gunakan kemampuan native agent yang tersedia.

Jangan mengarang hasil memory atau graph.

Jika root agent instruction sudah memuat atau meng-import rules tersebut dan current agent sudah menerimanya, jangan membuka ulang hanya untuk menambah context duplikat.

TARGETED REPO DISCOVERY

Jika context accelerator belum cukup, gunakan repo map, file listing, search, symbol search, atau targeted reads.

Urutan default:

1. Manifest/package metadata utama.
2. Build/framework config utama.
3. Struktur folder tingkat atas.
4. Script run/build/test/lint yang terlihat.
5. Entry point utama hanya jika diperlukan.
6. File tambahan hanya jika masih ada gap penting.

Contoh manifest/config dapat berupa:

* package.json
* pyproject.toml
* Cargo.toml
* go.mod
* pom.xml
* composer.json
* *.csproj
* Dockerfile
* docker-compose.*
* framework config
* workspace config

sesuai project.

Jangan berasumsi jenis project sebelum melihat bukti.

READ BUDGET

Gunakan progressive disclosure.

Jangan membaca source file satu per satu secara luas.

Jangan spawn banyak subagent hanya untuk "memahami repo".

Default target bootstrap:

maksimal sekitar 5 targeted project file reads di luar instruction/template yang memang perlu dimuat.

Ini adalah budget, bukan hard limit.

Boleh melewati budget sedikit jika struktur project tidak dapat dipahami dengan benar tanpa bukti tambahan.

Jika harus memperluas scope secara signifikan, berhenti dan catat bagian yang masih UNKNOWN daripada melakukan audit repository terselubung.

Tidak perlu meminta izin user untuk satu atau beberapa targeted read tambahan yang memang diperlukan untuk menyelesaikan bootstrap ini, selama tetap read-only dan dalam scope.

Jika environment atau permission system meminta approval, ikuti mekanisme permission tersebut.

SEARCH BEFORE READ

Untuk repository besar:

gunakan pencarian atau file map lebih dahulu.

Contoh:

* file tree terbatas,
* `rg --files`,
* symbol search,
* filename search,
* dependency graph,
* graphify query,
* atau kemampuan repository search milik agent.

Buka isi file hanya setelah ada alasan untuk membacanya.

Jangan melakukan recursive full-read.

ABAIKAN SECARA DEFAULT

Jangan membaca isi besar dari:

* node_modules
* vendor
* dist
* build
* .next
* coverage
* cache
* generated output
* binary
* large asset
* large log
* dependency cache

kecuali benar-benar diperlukan.

Lockfile boleh digunakan untuk mengidentifikasi package manager atau dependency resolution bila diperlukan, tetapi jangan membaca lockfile besar secara penuh pada bootstrap.

COMMAND

Fase bootstrap hanya boleh memakai command read-only dan ringan bila dibutuhkan.

Contoh:

* melihat working directory,
* melihat branch,
* `git status --short`,
* file listing,
* search,
* membaca manifest/config,
* atau query graph/index yang sudah tersedia.

Jangan menjalankan:

* dependency install,
* package upgrade,
* migration,
* production build,
* full test suite,
* full repository analyzer,
* Graphify rebuild,
* destructive command,
* commit,
* push,
* atau command yang mengubah project.

Jangan menjalankan command hanya agar terlihat aktif.

SOURCE OF TRUTH

Untuk kondisi implementasi saat ini:

repository aktual

>

memory/index lama.

Untuk aturan kerja:

instruction dengan scope yang berlaku

>

default assumption.

Untuk keputusan eksplisit user:

pertahankan keputusan user selama masih berlaku.

Jika README, memory, graph, dan implementation berbeda:

jangan diam-diam memilih versi yang nyaman.

Gunakan implementation/config sebagai bukti current state dan catat konflik yang material.

STOP CONDITION

Berhenti melakukan bootstrap saat sudah cukup mengetahui:

* stack utama,
* struktur folder inti,
* cara menjalankan project atau command utama jika terlihat,
* aturan coding penting,
* template/rules baseline yang aktif,
* dan gap yang masih belum diketahui.

Tidak perlu memahami seluruh business logic.

Tidak perlu membaca seluruh source.

Tidak perlu menemukan semua endpoint, model, component, atau feature sebelum task utama diketahui.

BATAS KERJA

* Jangan mengubah file apa pun.
* Jangan membuat source code.
* Jangan memperbaiki bug.
* Jangan refactor.
* Jangan install dependency.
* Jangan mengubah config.
* Jangan membuat branch.
* Jangan membuat commit.
* Jangan menjalankan migration.
* Jangan membuat plan implementasi besar sebelum task utama diketahui.
* Jangan melakukan web research hanya untuk memahami local repository.
* Jangan menebak informasi yang belum ditemukan.

Jika sesuatu belum dapat dipastikan, tandai:

UNKNOWN.

OUTPUT BOOTSTRAP WAJIB RINGKAS

Maksimal sekitar 8 bullet.

Cakup hanya yang relevan:

* Stack utama
* Struktur folder inti
* Cara menjalankan / command penting
* Aturan coding penting
* Instruction/rules yang aktif atau ditemukan
* Context accelerator yang berhasil digunakan, jika ada
* Hal yang masih UNKNOWN
* File/context utama yang diperiksa

Jangan keluarkan audit panjang.

Jangan menjelaskan seluruh isi setiap file.

Jangan mengulang rules yang baru dibaca.

SETELAH OUTPUT

Berhenti.

Tunggu task utama user.

Saat task utama diberikan:

1. prioritaskan task tersebut,
2. identifikasi area repo yang relevan,
3. muat hanya rule/template tambahan yang relevan,
4. baca hanya source yang diperlukan,
5. gunakan memory/graph/search sebagai accelerator jika membantu,
6. lalu kerjakan task sesuai instruction yang berlaku.

Jangan melanjutkan eksplorasi repo tanpa hubungan dengan task utama.
