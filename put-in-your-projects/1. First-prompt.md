# Bootstrap — sekali saat konteks project belum diketahui

Hormati instruction yang sudah dimuat host. Identifikasi stack dari manifest/config,
struktur utama, command run/build/test/lint yang benar-benar tersedia, dan rules relevan.
Gunakan pencarian sebelum membaca file; sekitar lima targeted reads biasanya cukup,
tetapi tambah bila perlu untuk menutup gap konkret. Jangan menganggap contoh sebagai fakta.

Bootstrap bersifat read-only. Jangan implementasi ticket, install dependency, membuat
branch/plan besar, menjalankan full audit/test, rebuild graph, atau memanggil semua skills.
Memory/graph hanya digunakan jika konteks yang hilang memang membutuhkan accelerator itu.
Berhenti saat konteks minimum cukup; laporkan ringkas stack, command, rules dan UNKNOWN.
Jika belum ada ticket, tunggu task. Jika ticket sudah diberikan, lanjutkan task tersebut.
