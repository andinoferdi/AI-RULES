# Query, cache and web optimization patterns
Baseline EXPLAIN ANALYZE before/after with representative parameters and write/read conditions. N+1 loops→join/include/batch; every list has stable order/limit. Large Seq Scan may mean unusable/missing index or legitimately low selectivity. Row estimate order-of-magnitude wrong→refresh statistics. Sort above scan may need equality-first then range/sort composite index. Leading wildcard needs trigram/fulltext; lower(email) needs expression index; rare value may benefit from partial index; covering index can avoid heap. An unchanged plan/gain inside noise does not justify permanent write tax.
One connection pool per process with instances×max below database cap. Measure queue wait vs query time, long transaction/leak/missing await before resizing. Unbounded autoscaling often needs a proxy. Set connection timeout; larger pools can move queue into DB.
Cache only measured expensive/read-heavy data. Choose in-process vs shared vs CDN based on consistency/topology. Key viewer/tenant/locale/permissions/flags; state staleness. Choose TTL, event/tag invalidation or versioned keys deliberately. Cache-aside and read-through differ loader ownership; write-through costs synchronous latency; write-behind has durability/data-loss window. Coalesce concurrent misses via shared in-flight promise/lock or stale-while-revalidate. Negative not-found sentinel uses short TTL; never cache origin errors. Bound memory/eviction and observe hit rate. Balances/access decisions/inventory-at-checkout may need fresh data.
Images declare width/height/source dimensions, modern responsive formats, LCP high fetchpriority/no lazy, below-fold lazy+async. Fonts subset/limit/preload only critical and use font metrics to reduce shifts. Split routes/heavy features; don't assume named ESM imports are a bundle problem. Profile expensive render before memoization. Batch reads then writes, compositor transforms/opacity, chunk long tasks or worker where supported.
Measure same command/cold-warm/sample/device conditions; medians and variance prevent noise wins. Keep correctness green and record both retained and discarded hypotheses. Synthetic CI and field p75 monitoring answer different questions.
