# Triage an incoming issue: procedure detail and bounded example

State domain: unlabeled→needs-triage→needs-info/ready-for-agent/ready-for-human/wontfix; reply returns needs-info to needs-triage. These are tracker roles, not Andino states. A ready-for-human brief names why delegation cannot finish it. Rejection KB groups requests by concept and durable reason; maintainer can confirm, reconsider or distinguish a new request.

## Run the example

This example uses only Python's standard library and writes inside the current working directory. Read the code, then run it only in a fresh disposable directory. The main repository's `scripts/check_andino_matt_methods.py --runtime-root <package>` executes this exact block in a TemporaryDirectory and independently checks the semantic results. No project files, index, external services or credentials are needed.

```python
from pathlib import Path
import json
issue={"category":"enhancement","state":"needs-triage","already_implemented":True,"evidence":"feature exists in fixture API"}
decision={"category":issue["category"],"recommended_state":"wontfix","reason":"already implemented","record_rejection":False,"external_write":False}
Path("triage.md").write_text("> This was generated by AI during triage.\nRecommendation: close as already implemented.\nEvidence: "+issue["evidence"],encoding="utf-8")
result=decision
Path("result.json").write_text(json.dumps(result,sort_keys=True),encoding="utf-8")
```

## What the observation establishes

Inspect both generated artifact(s) and `result.json`. The result is a bounded operational example for the procedure above; it does not simulate or assert model auto-activation. External CLI, browser rendering, TypeScript resolution, human decision quality and unavailable host behavior remain separate checks.
