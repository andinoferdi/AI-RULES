# Workspace and Isolation Guards

Internal Andino resource for `andino-delegation`. Operates under Andino Workflow governance.

## 1. Dual-Mode Workspace Architecture

To ensure flawless execution across Linux, macOS, and Windows (PowerShell / Git Bash), the workspace engine operates in **Dual-Mode**:

```
Workspace Resolution:
├── Mode 1: Isolated Git Worktree (Opt-in / POSIX Native)
│   ├── Creates independent linked checkout via `git worktree add`.
│   └── Recommended when tasks perform extensive structural renames or branch isolation.
└── Mode 2: In-Tree Scratch Workspace (Default & Cross-Platform Resilient)
    ├── Target directory: `<repo-root>/.andino/delegation/<plan-slug>/`
    ├── Houses task briefs, implementer reports, diff packages, and progress ledger.
    └── Enforces zero git pollution via self-ignoring root marker `.andino/.gitignore`.
```

### Self-Protecting `.gitignore`

Upon initialization, the workspace creator ensures that `.andino/.gitignore` contains:
```gitignore
# Auto-generated by Andino Delegation
*
!.gitignore
```
This guarantees that all generated briefs, raw reports, and review packages remain untracked by `git status` and immune to accidental commits.

## 2. Windows File-Locking & NTFS Defense

On Windows systems, background processes (Windows Defender, IDE indexers, shell extensions) frequently hold open file handles, causing:
- `PermissionError: [WinError 32] The process cannot access the file`
- `fatal: Unable to create '.git/index.lock': File exists`
- `EBUSY: resource busy or locked`

### Mechanical Invariants for Windows Survival

1. **Exponential Backoff Retry**: Any file write, directory deletion, or git index mutation must wrap in a 3-tier retry with jitter (200ms, 800ms, 2000ms).
2. **Explicit File Closure**: All file reads/writes in helper scripts must use contextual managers (`with open(...) as f:`) to guarantee instant file handle release.
3. **Stale Lock Pruning**:
   - Before failing on `index.lock`, check lock file modification time.
   - If `index.lock` is older than 10 seconds and no active git process exists in the process table, safely prune the lock file.
4. **Universal Path Normalization**: All paths in briefs and commands must use forward slashes (`/`) and `pathlib.Path.resolve()`, avoiding backslash escape corruptions in JSON/Markdown.

## 3. Compaction-Resistant Durable Progress Ledger

**Core Law**: The progress ledger on disk is the authoritative source of truth, outranking conversational recall.
- In long-running sessions, Claude Code triggers automatic context compaction.
- Controllers that rely on memory routinely re-dispatch completed tasks, wasting hundreds of thousands of tokens and overwriting git commits.

### Ledger Format (`.andino/delegation/<plan-slug>/progress.md`)

```markdown
# Delegation Progress Ledger — Plan: docs/plans/auth-refactor.md
Plan ID: auth-refactor
Base Commit: f3a8c12
Current State: ACTIVE

## Task Execution History
- Task 1: complete (commits a1b2c3d..d4e5f6a, review clean)
- Task 2: fix round 1/5 (2 addressed, 0 open; commits d4e5f6a..b7c8d9e)
- Task 2: complete (commits d4e5f6a..b7c8d9e, review clean)
- Task 3: complete (commits b7c8d9e..f9a0b1c, 1 parked)
  - Ruling: parked — minor mock warning — Ruling: code stands — zero risk

## Deferred Minor Findings
- Task 1: minor (deferred): extract JWT_EXPIRY_SECONDS to constant
- Task 3: minor (deferred): simplify header parsing regex

## Active Frontier
- Task 4 (deps: [Task 2, Task 3]) -> READY FOR DISPATCH
```

### Post-Compaction Recovery Protocol
1. Read `<workspace>/progress.md`.
2. Inspect the last recorded line:
   - If `Task <N>: complete`, advance to the next unblocked task on the active frontier.
   - If `Task <N>: fix round <R>`, resume the fix loop at round $R+1$.
3. Check `git log --oneline -n 5` to confirm recorded commits physically exist.
4. Resume dispatch immediately without asking the human for permission or replaying completed history.

## 4. Workspace Teardown and Cleanup

1. **Selective Deletion**: When all tasks and the final branch review pass, the controller purges the plan-specific directory:
   `rm -rf .andino/delegation/<plan-slug>`
2. **Sibling Isolation**: Never delete parent `.andino/delegation/` or sibling plan directories (`.andino/delegation/<other-plan>/`), which may belong to concurrent or paused tasks.
3. **Emergency Eject**: If a plan is aborted or circuit breaker trips, leave the workspace and ledger intact to allow human post-mortem and manual resumption.
