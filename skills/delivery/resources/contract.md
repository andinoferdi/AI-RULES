# Prepare a factual integration handoff — supporting contract

## Integration decision

Separate implementation from publication. File hashes identify an uncommitted candidate; release needs actual authorized commit/tag. Show branch/scope accurately without secrets.

Local merge is a Git mutation; PR is external publication; deployment affects users. A method grants none. Failed integration verification means preserve state and investigate, not force-push/clean.

Blockers identify criterion, safe attempts, missing prerequisite and independent work completed. Cite durable plan/evidence and one next action so handoff does not need chat history.
