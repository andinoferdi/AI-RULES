# Boundary implementation and audit details
STRIDE: spoofing→identity/signature, tampering→integrity/parameterization, repudiation→security audit log, disclosure→field allowlist/encryption/generic errors, DoS→bounded input/rate/timeouts, privilege→per-resource authorization. High/Critical security findings need reachable abuse scenario, location, impact, specific fix and evidence.
Use parsed schema output only; external replies/model output/OS-derived paths are untrusted. Hash passwords with appropriate argon2/scrypt/bcrypt work factor; session expiry/httpOnly/secure/sameSite and CSRF behavior explicit. Shared-store rate limits when multiple instances/serverless; in-memory max multiplies by instances. Headers CSP/HSTS/etc and explicit CORS origins; never wildcard with credentials. Whitelist upload MIME+magic/size, names/paths under ownership.
SSRF checks every resolved IPv4/IPv6, reserved/private/link-local/metadata/loopback, no redirect/credential/port bypass. DNS rebinding means validate-then-fetch may resolve twice; pin/filter actual connection. Do not claim URL regex solves SSRF.
Destructive leaf check resolves symlinks, rejects root and outside, verifies authenticated owner with integrity-protected evidence before teardown. Marker self-attestation and name-swap races remain limits; descriptor/no-follow or immutable hierarchy required if attacker can replace ancestors. Example only validates, no deletion.
Package audit: one installation boundary/manager/version/lockfile consistent with workspace+CI. Frozen npm/pnpm/Yarn commands differ by pinned client. Start scripts blocked/default-deny fail-closed, inspect exact source/version, approve minimum native policy, run clean immutable install. Never blanket-enable, force-fix or equate no known CVE with trust. Review ownership, maintainer/release/provenance/signature/transitives/typosquat/script changes; deferral has reachability/reason/review date.
PII: classify nonpersonal/personal/sensitive, minimum purpose and retention; actual export/delete from all copies/backups/indexes; applicable consent and third-party processing/region policy verified from current authority. Never expose real values in test/transcript.
LLM: output schema/encoding not eval/SQL/shell/path; system prompt isn't boundary, tool args validated in code, minimum tool authority, tenant RAG isolation, sensitive context excluded, recursion/rate/token limits. Model claims need independent evidence.
