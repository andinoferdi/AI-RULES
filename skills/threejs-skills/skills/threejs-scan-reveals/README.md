# threejs-scan-reveals

Build animated 3D scans from actual mesh topology in Three.js or WebGL. Use for a city survey pulse, a replayable world-space scanner that traces mesh edges over architecture, terrain or water, a staged construction reveal from structural wireframe to finished solids, or a character swap where dots and wireframe travel across the surface before it resolves.

choice or native skill. Read [GUIDE.md](GUIDE.md) for the method; its supporting
resources remain relative to this directory. Install the complete family:
