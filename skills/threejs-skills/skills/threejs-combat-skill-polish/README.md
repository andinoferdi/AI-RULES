# threejs-combat-skill-polish

Score a game's combat skills and spells out of 10 with blind judges, then raise the weakest to a bar, for timing and readability (does a skill read as itself, does the blow land when it lands) and for art (detail, light, trails, impact, art direction, judged against a reference such as Diablo IV). Covers filming casts on a stopped, stepped clock, contact strips and close-ups, anonymised two-judge rounds, the levers that moved scores, the traps that cost points, asset and load budgets, and shipping each skill as its own version. Use when the user asks to score, review, improve, polish or rebuild combat skills, spells or attacks; says a skill doesn't make sense, looks bad or should look like another game; names a target score; or starts a next skill thread.

This is an internal method bundled in `threejs-skills`, not an individual installer
choice or native skill. Read [GUIDE.md](GUIDE.md) for the method; its supporting
resources remain relative to this directory. Install the complete family:

```sh
ai-rules setup --host codex --capability threejs-skills --scope project --project-root . --source latest
```
