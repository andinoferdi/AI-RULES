# threejs-interactive-objects

Build interactive 3D objects for product pages and interfaces in Three.js - lit feature-grid objects that turn on hover, a hover lean with a click-to-inspect view you can turn and dolly, surfaces that break into grains around the pointer and reassemble, and detailed miniature control icons in a reusable atlas. Use for product instruments, hero sculptures, specimen viewers, feature cards and small interface controls.
