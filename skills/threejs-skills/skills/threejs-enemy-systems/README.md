# threejs-enemy-systems

Build or refactor reusable, data-driven enemy archetype and moveset systems for Three.js action games, plus rigged monster contracts and combat enemy AI. Use for enemy content schemas, model and rig conventions, combat move timing and contact contracts, runtime state boundaries, placeholder fallbacks, monster joints, sockets, hurtboxes and attack volumes, aggro, target selection, spacing, telegraphs, retreats, boss behavior, behavior-state machines, deterministic fixtures and AI regression tests.
