Cheat sheet EXPLAIN

  • Baca pohon dari node paling dalam ke atas.
  • cost=A..B: estimasi planner, A sebelum baris pertama, B sampai selesai.
  • actual time=A..B: waktu nyata dalam ms per loop; kalikan dengan loops.
  • rows estimasi jauh dari rows actual: statistik planner meleset.
  • Rows Removed by Filter besar: banyak baris dibaca lalu dibuang.
