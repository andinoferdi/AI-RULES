Kapan planner memilih Seq Scan, kapan Index Scan

Planner membandingkan estimasi cost tiap cara membaca tabel. Kalau filter mengambil sebagian kecil baris, Index Scan biasanya lebih murah. Kalau filter mengambil sebagian besar baris, membaca seluruh tabel secara berurutan lebih murah. (PostgreSQL docs 14.1, Use The Index, Luke)
