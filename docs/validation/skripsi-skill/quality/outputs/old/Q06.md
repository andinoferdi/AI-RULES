## 2. Ringkasan studi (bahan semua jawaban)

- **Studi dalam satu kalimat:** survei observasional satu waktu pada mahasiswa Program P semester 4 untuk mengestimasi hubungan antara frekuensi penggunaan AI dan skor regulasi belajar.
- **Hasil:** n = 40, rho Spearman = 0,12, p = 0,21, interval kepercayaan tidak tersedia. Hubungan sangat kecil dan tidak signifikan; data tidak cukup untuk menyimpulkan ada atau tidaknya hubungan.
- **Batas:** sampel sukarela, tanpa klaim keterwakilan, tanpa intervensi atau penugasan acak, tidak ada kesimpulan sebab akibat, hasil belajar tidak diukur.
- **Perubahan dari proposal:** analisis diubah dari Pearson sementara menjadi Spearman karena pengukuran ordinal.
- **Keputusan terkunci:** cakupan hanya Program P, sesuai arahan pembimbing.
