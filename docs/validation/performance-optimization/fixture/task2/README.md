# lumen-landing

Static landing page for Lumen, served from a CDN. No build step: the files in this folder are
what ships, except `js/vendor.js`, which is a readable stub of the production vendor bundle
(carousel and analytics SDK, about 380 KB minified in production).

- `index.html`: the page.
- `css/site.css`, `js/vendor.js`, `js/lazy.js`: styles and scripts.
- `img/`: images, generated by `python scripts/make_assets.py` (the setup already ran it).
- `reports/`: Lighthouse reports the marketing team ran against production.
- `python -m unittest` checks the page structure.

The page launched on 2026-11-03. It has too little traffic for Chrome UX Report field data;
there is no real-user monitoring on it yet.

Design can export the hero image in any size or format on request (about a day's turnaround).
