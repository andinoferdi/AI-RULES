# Andino Skills brand guide

One page for anyone who writes about, designs for or links to Andino Skills.

## The idea

**Done means proven.** / **Selesai berarti terbukti.**

Andino Skills are evidence-first skills for AI coding agents, written by Andino
(GitHub [andinoferdi](https://github.com/andinoferdi)). An agent that uses them
does not say "done" until every `Done when` point has passed a real check. The
skills work in English and Bahasa Indonesia.

The logo is a monoline **A** whose crossbar is a check mark. The letter is only
complete once the check is in place, the same way a task is only done once it is
proven.

## Logo files

All masters live in [`logo/`](logo/). They are SVG and stroke-based: the
geometry is drawn with round-capped strokes on a 256-unit grid (A stroke 32,
check stroke 28, wordmark stroke 22). Scale them as SVG; do not redraw them.

| File | Use |
|---|---|
| `andino-skills-horizontal.svg` / `-dark.svg` | Primary lockup: README header, slides, social cards |
| `andino-skills-stacked.svg` / `-dark.svg` | Square spaces: posters, profile banners |
| `andino-mark.svg` / `-dark.svg` | Symbol alone, when the name is already on screen |
| `andino-mark-black.svg` / `-white.svg` | One-colour printing, stamps, embroidery |
| `andino-icon.svg`, `andino-icon-512.png` | App icon, avatar, GitHub org picture |
| `social-preview.png` (1280×640) | GitHub social preview, link cards |

Use the `-dark` files on dark backgrounds. The light files lose the A on black.

The wordmark `andino skills` is custom lettering built from the same strokes as
the mark. Never retype it in a font.

## Clear space and minimum size

Clear space on every side: the stroke width of the check (about 1/9 of the
mark's height).

| Version | Smallest on screen |
|---|---|
| Horizontal lockup | 120 px wide |
| Stacked lockup | 80 px wide |
| Mark | 16 px (tested; the check still reads) |

Kunyit (turmeric) is the only accent. Keep it for the check and for one thing per
layout that marks "verified" or "done". Avoid purple and blue gradients and
sparkle icons: every AI tool uses them.

Approved pairs: full colour on white, dark version on `#0D1117` (GitHub dark) or
Tinta, black on white, white on Tinta or Kunyit.

## Voice

| Trait | Means | Does not mean |
|---|---|---|
| Plain | Short sentences, everyday words, real commands | Slang, hype, "revolutionary" |
| Proof-first | Every claim points to a check, file or command | Promising results nobody measured |
| Two languages, one voice | English and Bahasa Indonesia say the same thing, each in natural phrasing | Word-for-word translation |
| Generous | Credit upstream authors by name and link | Hiding where an idea came from |

Words we use: *proof, check, done when, evidence, real engineering*.
Words we avoid: *magic, superpower, 10x, revolutionary, seamless*. They promise
what no check can show.

## Don'ts

Do not stretch, rotate or recolour the mark outside this palette. Do not add
shadows, outlines or gradients. Do not separate the check from the A or move it.
Do not put the light logo on a busy photo without a solid panel behind it.

## Trademark note

No trademark search has been done for the name or the mark. Run one before using
them commercially.
